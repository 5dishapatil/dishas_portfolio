## 3. How to Supply Missing Authors, Covers, or New Books

1. **Override or confirm an existing book**: Edit `data/books/overrides.json` keyed by book ID (e.g. `"book-003"`, `"book-005"`, `"book-011"`, `"book-048"`, `"book-058"`) and provide `"author"`, `"isbn"`, `"coverUrl"`, or `"spineImageUrl"`.
2. **Append new books**: Drop a new wishlist export into `data/books/source/wishlist-*.txt` or add JSON objects to `data/books/source/manual-additions.json`.
3. **Rebuild the catalogue**: Run `npm run books:build` (which runs `import-books.mjs` followed by `resolve-covers.mjs`). The 3D street scene automatically adapts to any collection size.
